# Техдока (dev)

Индекс «Читать, чтобы...»:

- `architecture/` — как устроена система; читать, чтобы менять устройство
- `api/` — внешние и внутренние интерфейсы; читать, чтобы менять контракты
- `data/` — данные, схемы, миграции; читать, чтобы менять модель данных

Правило: после изменений кода синк этой папки — условие готовности фичи.
