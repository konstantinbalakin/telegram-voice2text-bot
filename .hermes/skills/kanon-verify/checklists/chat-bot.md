# Полигонный чек-лист: chat-bot

Пресет chat-bot (Telegram и аналоги). Прогонять на полигоне
(тестовый бот/чат), не на проде. Каждый пункт: pass / fail + сырой лог.

## 1. Жизненный цикл

- [ ] /start от нового пользователя → приветствие/онбординг корректен
- [ ] повторный /start существующим пользователем → идемпотентен
- [ ] /help → актуальные команды

## 2. Основной сценарий (ядро фичи)

- [ ] happy path: входное сообщение бота → ожидаемый ответ ≤ таймаута
- [ ] невалидный вход → понятная ошибка, бот не падает
- [ ] пустое/нестандартное сообщение (sticker, файл, капс) → предсказуемая
      реакция (даже «не понимаю»)

## 3. Границы

- [ ] длинное сообщение (макс. длина) → не обрывается молча
- [ ] быстрый спам сообщениями → не теряет и не дублирует ответы
- [ ] команда во время обработки предыдущей → очередь/отказ, не дедлок

## 4. Инфраструктура

- [ ] перезапуск процесса → состояние пользователей сохранено (БД/файлы)
- [ ] логи одного запроса можно проследить end-to-end (user_id, request_id)
- [ ] вебхук/polling жив после деплоя: бот отвечает в течение минуты

## 5. Регрессия фичи

- [ ] сценарии из whatsnew прошлых релизов → не сломаны
- [ ] `kanon check` зелёный
