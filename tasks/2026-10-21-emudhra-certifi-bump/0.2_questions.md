# Вопросы к К. и его ответы (2026-10-21, пакетно через clarify)

## В1. Версия certifi в requirements.txt

Предлагаю поднять пин `certifi==2026.1.4` → `certifi==2026.10.19` (текущий latest, eMudhra-фикс внутри).

**Ответ К.:** включено в дизайн без отдельного уточнения — пин 2026.10.19, возражений при ревью нет.

## В2. Обновление ca-certificates в образе при сборке

Системный стор контейнера берётся из базового образа `python:3.11-slim-bookworm` на дату сборки. Debian выпускает фикс, но момент неизвестен. Варианты: (а) apt-обновление + вырезать emSign ECC Root CA - G3 при сборке; (б) только apt-обновление.

**Ответ К.:** вариант (а) — детерминированно, станет no-op после фикса Debian.

## В3. Автодеплой после мержа PR

Мерж PR вызовет автотег (v0.0.80) и деплой на прод: контейнер пересоздастся, короткий (~секунды) простой бота.

**Ответ К.:** да, деплоить сразу после мержа.

## В4. CI-страховка на будущее
